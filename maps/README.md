# 下沉篇地圖

這個資料夾保存生成器產生的三份可匯入地圖。第一、二部分是獨立路線；第三部分保留玩家原始範本的地形、重力、水層與傳送結構，只補上完整遭遇曲線：

| 檔案 | 定位 | 設計重點 |
| --- | --- | --- |
| `下沉篇/下沉篇-第1部分.json` | 深海森林入口 | 維持 18 格寬、把長度擴成 160 列；四組寬闊環路繞過巨型森林岩體，縱向路程超過舊版兩倍。兩座托里切利空間位於四格寬、與主路隔牆的 L-1 回返洞，困難來自遠距離繞路而非微操。 |
| `下沉篇/下沉篇-第2部分.json` | 穿越熱泉 | 20×88 的左右熱泉分流；四條與主路隔牆的托里切利高風險回返洞、探索支路開門、L3 脈衝區與可選傳送捷徑。 |
| `下沉篇/下沉篇-第3部分.json` | 深淵遺跡 | 保留玩家原始 24×117 複雜遺跡；把前兩部分教過的物件、層間門與 39 段多邊傳送結構組成最終考題。 |

三份地圖都有唯一的玩家起點，並配置敵人、Mini Boss 或 Boss 的節點。遊玩頁會優先使用這個正式起點；在 Tile Editor 按右上方「匯入 JSON」後，也能直接看見所有節點。

要重新產生三份地圖，可直接在專案根目錄執行：

```powershell
npm run generate:maps
```

腳本會重新產生三份 odd-r 矩形地圖，並保留各自的路線節拍、關卡目標、難度與出生點設定。第一、二部分可獨立重現；第三部分永遠從 `範本map.json` 讀取玩家原始地形，生成器與測試都會阻止它被意外改寫。
