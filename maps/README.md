# 下沉篇地圖

這個資料夾保存生成器產生的三份可匯入地圖；第一、第三部分沿用既有範本，第二部分採獨立熱泉設計：

| 檔案 | 定位 | 設計重點 |
| --- | --- | --- |
| `下沉篇/下沉篇-第1部分.json` | 進入深海 | L-1、L0、L1 為主；障礙少；氧氣與檢查點先教會節奏。 |
| `下沉篇/下沉篇-第2部分.json` | 穿越熱泉 | **獨立熱泉脈衝路線**；20×96，分段熱泉室、交錯熱泉岩層、L3 脈衝區、回流電流與熱泉迴路傳送門。 |
| `下沉篇/下沉篇-第3部分.json` | 深淵遺跡 | 保留範本的最高複雜度，並補齊氧氣、危險、視野、重量與 Edge 互動。 |

三份地圖都刻意不放玩家出生點，方便先驗收地形與物件配置。使用方式是開啟 Tile Editor，按右上方「匯入 JSON」，選擇要測試的部分。

第一與第三部分仍以 `範本map.json` 作為既有地形來源；第二部分是生成器內獨立建立的熱泉路線，不會從第三部分複製後簡化。若範本更新，或要重新產生三份地圖，可在專案根目錄保留 `範本map.json` 後執行：

```powershell
npm run generate:maps
```

腳本會重新產生三份 odd-r 矩形地圖；第一、第三部分維持範本尺寸，第二部分維持自己的 20×96 熱泉尺寸，並保留 `metadata` 中的篇章、部分、難度與「未放置出生點」標記。
