# Player HUD icon assets

These are symbolic, flat Logo icons for the six HUD slots.

- `weapons/<id>/lv1.png` through `lv3.png`: active weapon families.
- `passives/<id>/lv1.png` through `lv3.png`: passive ability families.
- Each final icon is a transparent 128×128 PNG with a safe margin for the octagonal slot.
- Level colors are green for Lv1, blue for Lv2, and purple for Lv3.
- The same family keeps its core silhouette while adding simple geometric elements at higher levels.

Current families:

- Weapons: `knife`, `katana`, `trident`, `lightMachineGun`
- Passives: `oxygenCirculator`, `pressureStabilizer`, `ecologicalCarapace`, `abyssalAmplifier`
