# 六邊形水域素材驗收 Checklist

> 用途：驗收六邊形 Tile Editor 第一批水域 Cell 素材。
>
> 本清單只驗收 L3、L2、L1、L0、L-1 五種水域素材。不可通行障礙六邊形暫緩，等待下降篇與上升篇各三個篇章的障礙風格確定後再建立。

## 驗收前提

- [ ] 五張素材使用相同的六邊形外框、尺寸、視角與留白。
- [ ] 五張素材都是沒有厚度的平面六邊形；不可出現立方體側面、倒角、斜面或立體石塊外觀。
- [ ] 五張素材以正上方視角呈現；不可使用等角、透視或斜視角度。
- [ ] 素材是單一 Cell 的可重複使用圖，不是完整地圖拼圖。
- [ ] 水域視覺與 `gravityLevel` 分離；素材不直接畫出玩家速度或角色。
- [ ] 沒有文字、標籤、Logo、水印或額外角色。
- [ ] 外部背景已去除或可在編輯器中正確遮罩。
- [ ] 外框沒有明顯綠幕邊緣、白邊或黑邊。
- [ ] 素材保留古文明工程草圖、深海石雕、幾何構成與海水侵蝕質感。

## L3｜深色水域

- [x] 檔案已生成：[L3-deep-water.png](六邊形水域素材/L3-deep-water.png)
- [ ] 顏色是五級中最深的深藍／黑藍。
- [ ] 視覺傳達快速下沉與高壓迫感。
- [ ] 有低調的向下結構線或沉降紋理，但不是 UI 箭頭。
- [ ] 不搶過地雷、重石、敵人等 Cell 物件的辨識度。
- [ ] 與 L2、L1 並排時能立即辨識層級差異。

## L2｜深藍過渡水域

- [x] 檔案已生成：[L2-transition-water.png](六邊形水域素材/L2-transition-water.png)
- [ ] 顏色介於 L3 與 L1 之間，不能只是 L3 的淡化版。
- [ ] 視覺傳達中高重力與壓力正在增加。
- [ ] 有比 L1 更明顯、但比 L3 克制的沉降紋理。
- [ ] 與 L3、L1 並排時能看出獨立的第三種水域狀態。

## L1｜一般藍色水域

- [x] 檔案已生成：[L1-standard-water.png](六邊形水域素材/L1-standard-water.png)
- [ ] 是玩家最容易辨識的基準藍色。
- [ ] 視覺保持中性，不過度暗示危險或上浮。
- [ ] 石雕與工程線條仍然可見，但不能造成雜訊。
- [ ] 作為五級水域的比較基準時清楚易讀。

## L0｜中性色帶

- [x] 檔案已生成：[L0-neutral-band.png](六邊形水域素材/L0-neutral-band.png)
- [ ] 使用中性灰藍／石色，不與 L1 混淆。
- [ ] 視覺傳達「無垂直加速度但保留慣性」。
- [ ] 不畫成完全靜止、真空或消除速度的圖示。
- [ ] 與 L1、L-1 並排時能清楚表現轉換區。

## L-1｜淺色上浮水域

- [x] 檔案已生成：[L-1-rising-water.png](六邊形水域素材/L-1-rising-water.png)
- [ ] 顏色是五級中最淺，偏淺藍／青藍。
- [ ] 視覺傳達持續上浮，但不使用文字或直接 UI 箭頭。
- [ ] 有低調的向上流動或上升紋理。
- [ ] 與 L0、L1 並排時能立即辨識上浮方向的差異。

## 五張素材的整體驗收

- [ ] 五張圖縮放到編輯器 Cell 尺寸後仍能辨識。
- [ ] 五張圖疊加 Cell Overlay 後仍保留水域層級辨識度。
- [ ] 五張圖放置 Cell 物件後，物件輪廓仍清楚。
- [ ] 五張圖不依賴特定章節；第一章與第二章都能使用。
- [ ] 五張圖未包含不可通行障礙、章節專屬地形或未定義物件。
- [ ] 五張圖的命名、格式與尺寸一致。
- [ ] 已在 Git 中提交並上傳本次清單與素材。

## 暫緩項目：不可通行障礙六邊形

- [ ] 暫不生成。
- [ ] 等待下降篇三個篇章與上升篇三個篇章的障礙效果定義。
- [ ] 確認每個篇章的障礙原型、材質、傷害／阻擋效果與變異狀態後再建立素材清單。
