# 六邊形 Tile Editor

## 目標

Tile Editor 不是只用來畫背景，而是用來配置整個遊戲關卡：

- Cell 的地形與水域規則。
- Cell 上可重疊的環境物件。
- Cell 之間的 Edge 互動。
- 敵人、Boss、Checkpoint 與出生點。
- 第一章與第二章的同一地圖變異狀態。

## 資料模型

```text
Map
├── Cells
│   ├── 基礎地形
│   ├── 水域規則
│   ├── 環境效果
│   ├── Cell 物件
│   └── 角色／出生點
├── Edges
│   ├── 相鄰 Cell
│   ├── 邊方向
│   ├── 邊上的物件
│   └── 潮流資料
├── Actors
├── Checkpoints
└── Chapter States
```

## Cell

每個 Cell 需要有唯一的六邊形座標，並保存：

- 基礎地形。
- 水域規則。
- 環境效果。
- 一個或多個 Cell 物件。
- 角色與出生點。
- 關卡區域與 Checkpoint 資訊。

六邊形的鄰居不是上下左右四格，而是六個方向。Boss、敵人、氧氣與潮流都可以讀取鄰近 Cell。

## Edge

每個 Cell 的六條邊都可以對應到相鄰 Cell。

Edge 需要保存：

- 起始 Cell。
- 連接的相鄰 Cell。
- 六個方向中的方向。
- 邊界物件。
- 是否阻擋通行。
- 潮流方向與強度。

彈簧水母、尖刺與潮流都可透過 Edge 連接兩個 Cell，不需要另外拉一條自由線。

## 放置錨定規則

編輯器以素材的實際放置方式分類，而不是只以遊戲效果分類：

| 分類 | 放置方式 | 規則 |
| --- | --- | --- |
| 水域重力 | Cell Snap（整格） | 一次覆蓋整個六邊形 Cell，寫入該 Cell 的 `gravityLevel`。 |
| 水域上物件 | Free Snap | 可在畫布中自由定位，不強制吸到 Cell 中心；為了存檔與章節覆寫，資料仍由最近的 Cell 保存。 |
| 邊緣沾黏 | Edge Snap | 只能貼在兩個相鄰 Cell 的共用六角邊上，不會自由漂浮在 Cell 內。 |
| Actor／出生點 | 待定義 | 目前保留既有編輯器功能，但不在本輪替它指定最終放置或吸附規則。 |

選取後不再繪製額外的金色虛線六角環；Cell Snap 使用游標下的金色整格框，Edge Snap 使用游標下的金色共用邊，避免出現與放置無關的八卦狀提示。

地圖仍保存完整的 odd-r Cell 座標，但畫布會裁掉左右交錯凸出的半個六角尖角，維持固定橫向寬度；預設鏡頭為 `200%`，左右邊界剛好貼齊地圖，不額外留下空地。畫布本身是可上下捲動的鏡頭，捲動只改變目前看到的垂直位置，不改變縮放。地圖可以在最下方繼續新增 odd-r Cell 列，因此不繪製會暗示關卡終點的底部封口線。每條已佔用 Edge 都會在可通行水域的那一側，以該水域重力色加上較淺的白藍色，繪製「Cell 中心到共用邊」的三角扇區；層間轉接門因為兩側都是水域，兩個扇區都會標示。所有水域物件與 Edge 素材都使用白色透明輪廓，以便和扇區標記清楚分離。

## 官方預設與 Inspector

每個新放置的水域物件與 Edge 都會直接帶入下表的**官方預設**。關卡設計者可在右側 Inspector 對單一實例調整；再次用「選取」工具點該物件或 Edge 即可回到同一份設定。`恢復官方預設` 只重設該實例，不會覆蓋其他已調整物件。

| 類別 | 官方預設 | 可調整值 |
| --- | --- | --- |
| 墨水區 | 大小 `22 px`、可見範圍 `110 px` | 大小、可見範圍 |
| 深海地雷 | 大小 `17 px`、傷害 `24 HP` | 大小、傷害 |
| 重石 | 大小 `17 px`、破壞速度 `31 px/s`、下壓重量 `4 px/s` | 大小、破壞速度、下壓重量 |
| 氧氣礦石 | 大小 `17 px`、提供 `100 O₂`、釋放速度 `110 m/s` | 大小、氧氣量、釋放所需速度 |
| 光合作用氣泡 | 大小 `17 px`、提供 `20 O₂`、免疫重力 `2.5 秒` | 大小、氧氣量、免疫時間 |
| 托里切利空間 | 大小 `17 px`、氧氣恢復 `20 O₂/s` | 大小、恢復速度 |
| Checkpoint | 大小 `17 px` | 大小 |
| 一次性開門按鈕 | 大小 `24 px`、未按下 | 大小、指定一個或多個 `targetGates` |
| 彈簧水母 | 大小 `1.0 倍`、彈力 `1.08 倍` | 大小、彈力倍率 |
| 尖刺邊界 | 大小 `1.0 倍`、傷害 `20 HP` | 大小、傷害 |
| 水草／珊瑚群落 | 大小 `1.0 倍` | 僅大小 |

水域重力不在這份可任意調參的清單內，因為它使用固定的官方等級：`L3=2.0G` 向下、`L2=1.5G` 向下、`L1=1.0G` 向下、`L0=0G`、`L-1=1.0G` 向上。放置時直接選等級，不需要重新猜下降或上升數值。

### Cell 工具

- 選取 Cell。
- 塗刷基礎地形。
- 以 Cell Snap 設定 `gravityLevel`：`L-1`、`L0`、`L1`、`L2` 或 `L3`。
- 以 Free Snap 放置珊瑚與墨水區。
- 以 Free Snap 放置氧氣來源、地雷、重石、水草、Checkpoint 與剃刀。
- 以 Free Snap 放置一次性開門按鈕；選取按鈕後，在 Inspector 用分號分隔的 Cell 座標指定 `targetGates`。
- 以「條件通行門（L1）」整格 Tile 放置門。門固定是 L1：關閉時不可通行並顯示鎖鏈交叉封鎖；按鈕接觸後解除鎖鏈、顯示較亮的 L1 水域，而且每顆按鈕只觸發一次，不會複製其他 Cell 的重力。
- 玩家起點使用古文明遺跡潛水夫圖像，不再使用 `P` 文字標記；編輯器與物理測試共用同一個角色圖，並以漂浮、微擺、核心脈動與氣泡上升組成待機動畫。

### Edge 工具

- 以 Edge Snap 點選兩個相鄰 Cell 之間的 Edge。
- 放置彈簧水母。
- 放置尖刺或障礙。
- 設定潮流方向與強度。

### Actor 工具

- 放置玩家起點。
- 放置小怪出生點。
- 放置 Mini Boss。
- 放置 Boss。

### 預覽工具

- 預覽五級水域顏色與重力方向／強度。
- 顯示 Cell 疊加物件。
- 顯示 Edge 方向。
- 顯示氧氣來源與 Checkpoint。
- 預覽第一章與第二章的地圖狀態。

## Inspector

選取 Cell 時，Inspector 顯示：

```text
Cell 座標
基礎地形
水域規則（`gravityLevel`）
條件通行門狀態
環境效果
Cell 物件清單
角色／出生點清單
```

選取 Edge 時，Inspector 顯示：

```text
連接的兩個 Cell
Edge 方向
邊界物件
通行狀態
潮流方向
潮流強度
```

## 編輯流程

```text
建立地圖
↓
建立六邊形 Cell
↓
繪製基礎地形與水域規則
↓
配置 Cell 上的環境效果與物件
↓
配置 Cell 之間的 Edge
↓
放置敵人、Boss、Checkpoint 與出生點
↓
設定第一章狀態
↓
複製為第二章變異狀態
↓
執行地圖驗證
↓
進入遊戲預覽
```

## 第一章與第二章

兩章使用同一張地圖資料，但保存不同的 Chapter State。

```text
Map
├── Chapter 1：下沉篇
└── Chapter 2：上浮篇
```

第二章可以修改：

- Cell 物件。
- Edge 物件。
- 敵人出生點。
- 水域規則。
- 地圖中的突破路徑。

整體六邊形骨架不改變，但物件與空間可以變得更加刁鑽。

## 地圖驗證

Tile Editor 至少需要檢查：

- 每個 Cell 是否有唯一座標。
- Edge 是否真的連接相鄰 Cell。
- 是否有沒有連接 Cell 的孤立 Edge。
- 不可通行 Cell 是否仍被設定為可通行出生點。
- Checkpoint 是否有所在 Cell。
- Boss 與 Mini Boss 是否有出生位置。
- 氧氣來源是否有所在 Cell。
- `gravityLevel` 是否為 `L-1` 至 `L3` 的有效值。
- 疊加物件是否觸發未定義的互斥組合。
- 第一章與第二章是否仍然保留相同的地圖骨架。
