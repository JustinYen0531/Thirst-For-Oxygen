# 地圖元素分類

## 核心概念

這不是單純的六邊形地圖，而是六邊形 Tile Editor。

設計方向是：

> 所有遊戲元素都依附在六邊形網格上。

## 六邊形網格的五個層級

### 1. Cell：面

代表一個六邊形區域本身。

目前 GDD 中屬於 Cell 基礎層的內容：

| 元素 | Cell 角色 |
| --- | --- |
| 深色水域（`L3`） | `2.0G` 向下，快速下沉 |
| 深藍過渡帶（`L2`） | `1.5G` 向下，介於一般與高重力 |
| 一般藍色水域（`L1`） | `1.0G` 向下，基準重力 |
| 中性色帶（`L0`） | `0`，無垂直加速度但保留慣性 |
| 淺色水域（`L-1`） | `1.0G` 向上，持續上浮 |
| 不可通行區域 | 障礙或不可穿越空間 |

水域規則與基礎地形是不同欄位，因此一個 Cell 可以同時有「地形」與「水域規則」。水域規則應保存 `gravityLevel`，而不是保存玩家速度；速度屬於 Actor 的運動狀態。

### 2. Cell Overlay：面上的環境效果

作用範圍覆蓋一個 Cell 或一片 Cell，不一定是可拾取物件。

目前 GDD 中屬於此層的內容：

| 元素 | 效果 |
| --- | --- |
| 珊瑚安全區 | 不受傷害；小 Boss 以下敵人停止追擊 |
| 墨水區 | 限制視野，只能看見自身周圍 |

### 3. Cell Object：面上的物件

物件放在 Cell 內，可以和 Cell 的地形與水域規則重疊。

目前 GDD 中屬於此層的內容：

| 元素 | 效果 |
| --- | --- |
| 深海地雷 | 強力反彈與額外傷害 |
| 重石 | 向下墜落，可被力量足夠的撞擊擊碎 |
| 水草 | 可附著；附著期間不受重力並可等待體力恢復 |
| 托里切利空間 | 含氧浮島，安全時間短 |
| 光合作用氣泡 | 慣性移動並暫時免疫重力 |
| 含氧礦石 | 高速撞擊後釋放氧氣 |
| Checkpoint | 回滿生命、氧氣與體力，並作為死亡返回點 |

### 4. Edge：邊

代表兩個相鄰 Cell 之間的互動。

目前 GDD 中最適合放在 Edge 的內容：

| 元素 | Edge 角色 |
| --- | --- |
| 彈簧水母 | 在兩格之間提供固定方向反射 |
| 障礙物／尖刺 | 阻止穿越或在穿越時造成傷害 |
| 潮流 | 在兩格之間提供橫向推力，類似水平重力 |

潮流目前只定義了橫向推力與強度；它最後是放在 Edge，還是作為大範圍 Cell 效果，尚未定義。

### 5. Actor：角色與出生點

角色不是 Tile 本身，而是依附在 Cell 上行動的動態單位。

目前 GDD 中屬於此層的內容：

- 玩家
- 一般小怪
- 精英怪
- 變異精英怪
- Mini Boss
- Final Boss
- 小怪出生點
- Boss 出生點

角色可以讀取所在 Cell、鄰近 Cell 與 Edge 的資料。

## 不屬於 Tile 的內容

以下內容會影響地圖上的角色，但不是地圖格子或地圖物件：

- 武器：小刀、武士刀、三叉戟、輕量機槍。
- 被動能力與 Build。
- 氧氣、體力、生命與命數等玩家資源。
- 經驗值與升級選擇。
- 戰鬥中的攻擊、彈幕與冷卻。

這些應該是角色、系統或遊戲狀態資料，不應直接做成 Tile。

## 疊加規則

目前 GDD 沒有定義所有互斥規則，因此編輯器應採用「允許放置、交由驗證器警告」的方式。

### 可以直接重疊的基本結構

```text
Cell
├── 基礎地形
├── 水域規則
├── 環境效果
├── Cell 物件
└── 角色／出生點
```

例如：

```text
高重力水域
+ 深海地雷
+ 小怪出生點
```

### 目前尚未定義的重疊

- 珊瑚安全區與墨水區是否能重疊。
- 水草與深海地雷是否能在同一格。
- 同一格能放幾個氧氣來源。
- 同一條 Edge 能否同時放置障礙、彈簧水母與潮流。
- Boss 出生點與其他物件的互斥規則。
