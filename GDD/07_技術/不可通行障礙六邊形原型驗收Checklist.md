# 不可通行障礙六邊形原型驗收 Checklist

> 本輪範圍：先製作中性章節原型，不進入六個篇章與變異版本的完整擴展。
>
> 碰撞假設：整個六邊形 Cell 都不可通行；中心節點與角落連接線是拼接視覺與拓撲識別，不另外決定碰撞範圍。

## 拓撲規則

- [ ] 每張圖只有一個六邊形 Cell。
- [ ] 六邊形是平面素材，沒有厚度、側面、倒角或等角透視。
- [ ] 六邊形中心有一個清楚的中心節點。
- [ ] 連接線只從中心節點延伸到六個角落中的指定角落。
- [ ] 連接線確實抵達角落，不在邊界前提早消失。
- [ ] 未啟用的角落沒有多餘短線、殘線或錯誤接點。
- [ ] 相鄰六邊形共用同一個世界角落時，兩張圖的線端可以視覺接合。
- [ ] 不使用文字、數字、箭頭、UI、角色、Logo 或水印。
- [ ] 材質符合古文明工程草圖、深海石雕、幾何構成與海水侵蝕風格。

## 連接角落命名

以正上方角落為 `C0`，順時針依序為 `C1`～`C5`：

```text
             C0
        C5         C1
        C4         C2
             C3
```

每張素材的連接遮罩使用六位元表示：

```text
bit 0 = C0，bit 1 = C1，依此類推至 bit 5 = C5
```

## 單張素材驗收

- [x] 檔案為 RGBA PNG。
- [x] 四個角落透明，沒有綠幕或背景殘留。
- [x] 七張素材尺寸一致，皆為 `1254×1254`。
- [x] 六邊形外框位置一致。
- [x] 中心節點位置一致。
- [x] 連接線粗細、材質、亮度一致。
- [ ] 素材縮小到 Tile Editor 的 Cell 尺寸後，連接拓撲仍然可辨識。

## 拼接驗收

- [ ] 一角＋一角可以在共享角落形成連續接點。
- [ ] 兩角＋兩角可以在共享角落形成連續接點。
- [ ] 三角拓撲不會超出六邊形邊界。
- [ ] 兩個相鄰六邊形不會出現明顯斷線、錯位或雙重中心節點。
- [ ] 三個六邊形共用同一角落時，接點仍然可讀。
- [ ] 旋轉原型後，所有角落方向仍符合同一套命名規則。
