# 區域對稱表

兩章的對稱性不是「完全相同的場景複製」，而是區域功能與敘事位置互相呼應。

| 下沉篇 | 上浮篇 | 對稱關係 |
| --- | --- | --- |
| 入口 | 淺海 | 旅程起點與逃亡出口 |
| 深海森林 | 珊瑚 | 兩種海洋生態環境 |
| 熱泉 | 海溝 | 具有強烈環境壓力的區域 |
| 遺跡（下沉狀態） | 遺跡（上浮狀態） | 同一樞紐地點的前後狀態 |

## 對稱但不重複

- 下沉篇讓玩家學會地圖骨架與物件語言。
- 上浮篇讓玩家重新讀取同一套骨架，但友善物件減少、危險物件增加，原本熟悉的路線不再安全。
- 遺跡是最重要的對照點：它同時證明玩家曾經到過這裡，也展示寶藏被取走後世界發生了什麼。
