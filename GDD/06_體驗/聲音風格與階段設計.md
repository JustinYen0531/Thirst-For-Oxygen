# 聲音風格與階段設計

## 核心定位

本作的聲音風格定義為：

> **古文明聲學工程（Ancient Acoustic Engineering）**

聲音應像由石雕、貝殼、骨質結構與海水共同形成的遠古聲學系統，而不是現代機械或科幻電子設備。

## Lore 運用

深淵核心與深海生命都會透過共鳴回應彼此。聲音因此不只是氣氛，而是玩家理解世界狀態的敘事訊號。

- 下沉篇的聲音代表仍在運作、但已經被慢性污染的生命循環。
- 拔出核心的瞬間應讓聲音像一個被拔出的心臟或斷裂的聲學結構，明確標示世界進入新的狀態。
- 上浮篇保留下沉篇的音程與節奏，但加入失諧、斷拍、破碎回聲與不穩定呼吸，讓玩家聽見「同一個世界正在病變」。
- 深海之王的聲音應像守護者對裂口與核心的回應，而不是與世界無關的反派主題。

## 視覺到聽覺的轉譯

| 視覺語言 | 聽覺語言 |
| --- | --- |
| 幾何結構 | 規則脈衝、重複音程、清楚的節拍單位 |
| 工程草圖 | 不完整音句、可聽見的線條感、保留空白 |
| 仿生學 | 呼吸、低頻叫聲、甲殼與生物摩擦聲 |
| 石雕與侵蝕 | 厚重低頻、空洞共鳴、石材碰撞與裂解聲 |
| 青藍螢光 | 稀有的晶體泛音、短促高頻脈衝 |
| 功能即造型 | 每個聲音都要讓玩家理解攻擊、警告或狀態 |

避免使用：現代科幻、賽博朋克、EDM、可愛卡通、英雄式交響樂、過度金屬機器感。

## 3 個 Phase 與 3+3 結構

設計不是 6 個互不相關的風格，而是 3 個核心聲音母題，各自擁有常態小怪版與 Boss 版。

```text
Phase I：沉睡與探測
Phase II：共生與壓力
Phase III：核心與失衡
```

| Phase | 常態小怪 | Boss |
| --- | --- | --- |
| I 沉睡與探測 | 稀疏短句、單次呼吸、微弱石質敲擊，母題尚未完整 | 同一母題被拉長、放大，形成遠距離的古老召喚與共鳴 |
| II 共生與壓力 | 多個短脈衝互相回應，像生物之間傳遞訊號 | 同一脈衝變成儀式性多層節奏，形成更大的壓迫感 |
| III 核心與失衡 | 缺拍、斷裂泛音、短暫失控，像個體受到核心影響 | 同一母題完整爆發，低頻持續共鳴，像整個區域都被核心控制 |

## 下沉篇與上浮篇

兩篇共用同一組 Phase 母題，但聲音狀態不同。

### 下沉篇：平衡中的深海

- 音程完整。
- 脈衝規律。
- 回聲乾淨。
- 呼吸穩定。
- 聲音之間保留寬廣空間。

### 上浮篇：受衝擊後的深海

- 保留原本的核心音程與節奏，使玩家仍能認出它。
- 加入輕微失諧、缺拍、破碎回聲與不穩定呼吸。
- 部分聲音提前或延遲，像系統失去同步。
- 青藍高頻泛音變得刺耳、斷裂或過度明亮。
- 低頻壓力增加，但不是單純把音量變大。

因此整體結構是：

```text
3 個 Phase 母題
× 常態小怪／Boss 兩種層級
× 下沉篇／上浮篇兩種狀態
```

不是製作完全不同的音樂，而是讓同一個聲音精神在不同生命層級與世界狀態下變形。

## 聲音風格提示詞

```text
古文明深海仿生聲景，像一套由石雕、貝殼、骨質結構與海水共鳴構成的遠古聲學工程。低頻厚重、空洞、受到水壓限制；中頻使用石材摩擦、甲殼碰撞、乾燥敲擊與生物呼吸；高頻只使用稀有的玻璃與晶體泛音，代表符文、眼睛與能量核心。加入遙遠生物低鳴、失真的水下回聲、不完整的幾何脈衝與克制的儀式節奏。聲音具有古老、功能性、仿生、侵蝕與失衡感，不使用現代科幻、賽博朋克、EDM、流行旋律、可愛卡通、英雄式交響樂或過度金屬機器感。
```
