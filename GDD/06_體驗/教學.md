## 第一次遊玩：安全的學習順序

### 不要一開始就追求最遠距離

這個遊戲的第一個陷阱，是把「拉得越遠」誤會成「玩得越好」。你每次彈射都在交換三件事：

- **距離**：你能不能到下一個 Cell 或氧氣來源。
- **速度**：你能不能穿過敵人與危險區。
- **資源**：你是否還有氧氣與體力做下一次修正。

因此第一輪練習請遵循這個順序：

1. 先用短拖曳，觀察潛水員放開後會保留多少慣性。
2. 再進入相鄰 Cell，確認重力不是瞬間把你吸到某個點，而是從下一個物理步長開始改變速度。
3. 找到第一個氧氣來源後，再嘗試長距離彈射。
4. 把敵人當成路線中的成本，不要把每一隻都當成必須清除的目標。
5. 到達 Checkpoint 後才把它當成新的練習起點。

### 序章不是戰鬥教學

開場的三張故事資訊卡是世界觀入口，不是要你同時操作戰鬥、氧氣或物理。閱讀期間：

- 點擊或按 `Space` 推進文字。
- 文字尚未打完時，第一次操作會先顯示完整文字；第二次才換頁。
- 可以略過三頁序章，但不會略過後續閘門與航程節點演出。
- 序章期間會暫停物理、敵人、戰鬥與氧氣倒數。

三頁要傳達的是：氧氣正在崩潰、機械無法接近核心、只有活著的肉身能與核心共鳴。你讀懂這三件事，就已經知道主角為什麼必須親自下去。

> 第一輪不必背數值。先記住「拉、放、看水域、找氧氣、再決定要不要打」這條節奏，深海會自己把其餘規則教給你。

## 操作與彈射移動

### 基本操作

| 動作 | 操作 | 你實際改變的是什麼 |
| --- | --- | --- |
| 開始瞄準 | 點擊潛水員或畫面中的可操作區域 | 進入瞄準狀態，開始消耗瞄準所需的體力。 |
| 調整方向 | 按住並拖曳 | 拉曳方向決定彈射方向；拉曳距離決定初速度強弱。 |
| 發射 | 放開 | 套用一次初速度，之後由水域、潮流與碰撞持續影響。 |
| 閱讀序章 | 點擊或 `Space` | 只在序章／敘事卡片中推進文字。 |
| 取消或返回 | 使用頁面提供的 `Back` | 回到主頁，不會把文字教學誤當成遊戲內暫停。 |

畫面上的直線只是**方向與拉力距離提示**。它不會預告水域重力、潮流、特殊加速度造成的曲線，也不承諾你會停在直線終點。真正的路線判讀要留給你自己完成。

### 彈射不是瞬間位移

每一次發射都遵循這個順序：

```text
拖曳方向與距離
        ↓
設定彈射初速度 v₀
        ↓
固定步長套用水域、潮流與特殊狀態
        ↓
更新速度與位置
        ↓
處理反彈、阻擋與傷害
        ↓
繼續飛行，直到下一次發射或狀態改變
```

遊戲化運動模型如下：

```text
a_total = a_zone + a_current + a_special
v_next = clamp((v_current + a_total × Δt) × water_drag, -v_max, v_max)
p_next = p_current + v_next × Δt
```

- `a_zone`：所在 Cell 的水域重力。
- `a_current`：潮流等環境提供的水平推力。
- `a_special`：Boss、重力場或特殊物件暫時加入的加速度。
- `water_drag`：輕微水中阻尼，避免零重力下無限漂移。
- `v_max`：速度上限，避免高速讓落點與鏡頭失去可讀性。

### 實戰中的瞄準節奏

當氧氣或體力不足時，不要連續用最大拉力。可以採用：

1. 短拉，落入下一個較安全的 Cell。
2. 先確認自己所在水域的重力方向。
3. 用少量修正穿過障礙或敵人。
4. 靠近氧氣來源後，再規劃下一段長距離。

這套節奏看起來慢，卻能把「一次失誤直接缺氧」變成「還有機會修正」。

## 氧氣、體力、生命與經驗

### 四種玩家狀態

| 狀態 | 用途 | 歸零／不足時的後果 |
| --- | --- | --- |
| 氧氣 O₂ | 生存倒數，也是彈射與深海活動的核心資源。 | 氧氣歸零視為生存失敗，扣除一條永久命。 |
| 體力／能量 | 瞄準與發射的節奏資源。 | 不能無限連續瞄準或發射，需要漂移、附著或等待恢復。 |
| Health | 目前原型為 `0–100`，承受敵人與環境傷害。 | 歸零扣除一條永久命。 |
| Lives | 初始三條，是整趟遊玩的失敗容錯。 | 歸零後永久死亡，必須重新開始這一回合。 |

### 氧氣的目前可玩契約

目前 GDD 將氧氣定義為固定時間資源：滿氧約 **40 秒**歸零。這代表氧氣不再偷偷跟拉力、距離或發射次數乘上一個玩家看不見的倍率；你的真正判斷是「在這段固定時間內，能不能走到下一個補給點」。

氧氣的設計意義有兩層：

1. **生存倒數**：你不能永遠留在深海。
2. **路線燃料**：每一次移動都要讓你更接近下一個能呼吸的地方。

### 體力恢復

- 發射與瞄準會消耗體力。
- 最後一次發射後，停止操作約一秒，即使角色仍在漂移也會開始恢復。
- 水草等可附著物件提供等待體力恢復的安全節點。
- 部分擊殺與能力可以補回體力，這是戰鬥路線的回報之一。

### 資源充足時的自然回血

生命恢復看的是氧氣與體力中**較低的百分比**，不是只看其中一條：

| 兩項資源的較低者 | 原型回血速度 |
| --- | ---: |
| 低於 60% | 不觸發自然回血 |
| 至少 60% | 每秒 2 HP |
| 至少 80% | 每秒 5 HP，不與 2 HP 疊加 |

回血不超過 100 HP，也不會讓已經死亡或永久死亡的角色復活。氧循環器提高氧氣上限後，門檻會依比例重新計算。

### 經驗與升級

敵人死亡時會在原地留下經驗光點。光點不會自動追蹤你；你必須靠近拾取，所以「打贏」和「安全拿到經驗」是兩個決策。

| 敵人層級 | 經驗值 |
| --- | ---: |
| Tier 1 | 14 |
| Tier 2 | 24 |
| Tier 3 | 38 |
| Tier 4 | 58 |
| Mini Boss | 150 |
| 變異 Mini Boss | 220 |
| Final Boss | 600 |

達到升級門檻後，遊戲會暫停，讓你先決定要強化武器還是能力，再回到深海。完整清除一條可擊殺路線，才有機會拿到全部升級；閃避是合法選擇，但會犧牲經驗與可能的續航回報。

## 水域重力與物理

### 五級水域

重力是 Cell 的規則，不是放在格子中央的小物件。進入新 Cell 時保留當前速度，下一個固定物理步長才套用新水域的加速度。

| 層級 | 視覺／用途 | 持續加速度 | 玩家感受 |
| --- | --- | ---: | --- |
| `L3` | 深色水域 | `2.0G` 向下 | 快速下沉，留給你的修正時間最短。 |
| `L2` | 深藍過渡帶 | `1.5G` 向下 | 在正常與高壓之間建立壓力遞增。 |
| `L1` | 一般藍色水域 | `1.0G` 向下 | 基準環境，學習彈射的標準。 |
| `L0` | 中性色帶 | `0` | 沒有垂直加速度，但仍保留慣性。 |
| `L-1` | 淺色水域 | `1.0G` 向上 | 持續上浮，讓逃亡也成為環境力量。 |

### 讀懂重力的三個關鍵

- `L0` 不代表你會停住；高速進入仍會繼續漂移。
- 光合作用氣泡的重力免疫只移除暫時的水域加速度，不會清除你原本已經有的速度。
- 碰撞只改變速度向量；反彈後仍會受到所在水域重力影響。

因此，進入新 Cell 時不要只看顏色，也要看自己當下的速度。你是在「被新的重力拉走」，還是在「帶著舊速度穿過它」？這就是路線是否可控的差別。

## 氧氣來源：何時冒險、何時撤退

氧氣來源不是裝飾，也不是把路線變簡單的免費補血點；它們是關卡用來安排「風險換穩定」的節奏工具。

| 來源 | 取得方式 | 回復／效果 | 最重要的風險 |
| --- | --- | --- | --- |
| 托里切利空間（脫離切力空間） | 走進位於轉折、高處或側路的含氧空間 | 常駐、可反覆取得穩定氧氣 | 要先離開主戰場，走一條艱辛的上行或繞路；不會放在中央白給。 |
| 光合作用氣泡 | 直接碰觸 | 回復約 `50 O₂`，約半條氧氣槽；短時間慣性移動並免疫重力 | 失去重力約束後容易失控，可能穿過想去的路線或掉入更糟的位置。 |
| 含氧礦石 | 用高速肉身撞擊 | 撞開後釋放有限氧氣 | 你必須用自己承受撞擊的方式取得資源，位置通常不安全。 |
| 清氧氣泡 | 碰觸 | 立即回復 `25 O₂`，不提供重力免疫 | 一次性補給；Boss 遭遇啟動後會依時間重新生成。 |

### 托里切利空間的正確用法

看到它時，請把它當成「危險路線盡頭的無限呼吸站」，不是中央的休息椅：

1. 先確認從主戰場離開後，回程是否有足夠氧氣。
2. 觀察入口上方、側邊或轉彎後是否還有第二段水域重力。
3. 用短彈射逐格靠近，不要因為看到氧氣就直接把全部體力花在最後一跳。
4. 到達後把它視為路線錨點，回到 Boss 房或探索區重新選擇戰鬥與撤退。

**Boss 房至少有一個常駐托里切利空間**，但它必須放在入口上方、側角或轉折支路。這是為了讓玩家付出路線風險後取得穩定氧氣，而不是站在 Boss 房正中央無限補給。

第二章的上浮篇會更依賴這種高風險穩定氧氣：路線減少友善物件、重力與污染增加，重要區域應安排多個需要繞路取得的常駐氧氣節點，讓玩家用艱辛路徑換回可控的呼吸節奏。

> 一個好氧氣點的問題不是「它在哪裡」，而是「玩家為了拿到它，願意冒多少風險，又能不能活著回來」。

## 環境物件與路線判讀

| 物件 | 行為 | 玩家應對 |
| --- | --- | --- |
| 珊瑚安全區 | 不受傷害；小 Boss 以下敵人會停止追擊。 | 把它當成短暫整理路線與呼吸節奏的安全島。 |
| 彈簧水母 | 提供固定方向反射，符合入射角等於反射角。 | 先看反射後會進哪個重力區，再決定撞入角度。 |
| 深海地雷 | 碰撞造成強力反彈與額外傷害。 | 不要把它當成普通牆；它會同時改變血量與路線。 |
| 潮流 | 提供不同強度的橫向推力。 | 把它當成水平重力，讓它幫你位移，也要預留修正體力。 |
| 障礙物／尖刺 | 阻擋穿越，部分會造成傷害。 | 不要用最大拉力硬撞；先讓反彈角度服務你的下一次移動。 |
| 重石 | 自然向下墜落；向上撞擊力量不足時會壓下玩家，力量足夠時可擊碎。 | 判斷重石與高重力的疊加，不要在下方停留太久。 |
| 墨水區 | 限制視野，只看得到自身周圍。 | 用短距離試探，依照記憶與 HUD 回饋重建附近路線。 |
| 水草 | 可附著；附著期間不受重力，並可等待體力恢復。 | 把它當成恢復體力的暫停點，不要急著離開。 |
| Checkpoint | 更新死亡返回位置，並回滿生命、氧氣與體力。 | 啟用後是新的路線基準，但不會增加永久命數。 |
| 剃刀 | 刀片繞中心軸旋轉，接觸造成傷害並將角色推離。 | 看旋轉週期，利用它的推力而不是只把它當傷害牆。 |
| 一次性開門按鈕 | 接觸後只觸發一次，開啟指定通行門。 | 先確認按鈕控制的門，避免開門後才發現新的重力路徑。 |

### 門與按鈕

條件通行門是一整格固定使用 `L1` 的水域門。它初始以鎖鏈封住，按下指定按鈕後解除鎖鏈並亮起；通行與重力規則不會突然改成另一種。

這類路線的判讀順序是：

```text
看到封門 → 找到一次性按鈕 → 記住 target gate
        → 回到門前 → 重新讀取 L1 水域與周圍氧氣
```

## 戰鬥、敵人與 Boss

### 戰鬥不是唯一答案

核心循環是：

```text
探索 → 彈射 → 消耗氧氣與體力 → 找到補給
  → 擊殺或閃避 → 撿取經驗 → 升級 Build
  → 通過 Boss → 進入下一區域／承受上浮後果
```

每一場戰鬥都問自己三個問題：

1. 這個敵人擋住的是必經路，還是只是經驗？
2. 擊殺後留下的經驗光點，我能安全拿到嗎？
3. 為了戰鬥消耗的氧氣與體力，會不會讓我回不到下一個氧氣點？

### 敵人分層

| 分層 | 下沉篇 | 上浮篇 | 玩家應理解的意義 |
| --- | --- | --- | --- |
| Lv.1 教學型 | 爆腹燈籠魚、求援幼年海馬 | 移除 | 第一章建立信心；世界崩潰後不再保留這種友善教學生態。 |
| Lv.2 核心小怪 | 螃蟹守衛、龍蝦士兵、獅子魚砲手、魷魚刺客 | 四種保留 | 全遊戲最主要的戰鬥池，各自要求近戰、耐久、遠程或突襲應對。 |
| Lv.3 精英 | 蝦蛄戰將、鸚鵡螺祭司、弧潮獵鰩 | 以變異後的 Lv.4 形式出現 | 改變戰場規則，不只是把血量變厚。 |
| Lv.3 特殊生命 | 不出場 | 裂殖燈籠魚、珊瑚背海馬 | 以分裂、生命連結、治療與無敵狀態改變戰場。 |
| Lv.4 變異精英 | 不出場 | 變異蝦蛄戰將、變異鸚鵡螺祭司、變異弧潮獵鰩 | 你認得牠們原本的樣子，但必須重新學會應對。 |

第一章的三種精英在生命剩餘約 30% 時會進入怒氣模式：冷卻加快、外觀發光並長出黑色深海結晶。它們不靠無限新增技能作弊，而是把原有壓力變得更密集。

### Boss 房的通用規則

- 每一個 Boss 房至少有一個常駐托里切利空間，但位置在上方、側邊或轉折支路。
- Boss 戰中會依時間刷出清氧氣泡，提供 `25 O₂` 的一次性補給。
- 光合作用氣泡可回復約半條氧氣，但會讓你暫時失去重力約束；補給本身也是路線風險。
- Boss 不是只測試你的傷害數值，而是測試你能不能同時讀懂氧氣、重力、潮流、碰撞與敵人技能。
- 每章有兩個 Mini Boss；全程有四個 Mini Boss 加一個 Final Boss。

### Mini Boss 與 Final Boss 的故事功能

下沉篇的 Boss 是仍在維持封印與生態秩序的守護者。上浮篇的變異 Boss 不是突然換了一套無關技能，而是原有技能留下 **Aftermath**，與污染、重力、潮流、氧氣與敵人互相連鎖。

Final Boss 深淵抹香鯨（原名深海之王）是帶著遺跡游動的深海守護生物，不是戴王冠的人形反派。牠的主要戰場規則包括：

| 能力 | 你會遇到的壓力 |
| --- | --- |
| 深海召令 | 召喚生物或祭祀內容，讓戰場目標不只剩 Boss 本體。 |
| 遺跡重現 | 背部遺跡展開，讓古代構造成為戰場的一部分。 |
| 深淵化身 | 生成大型回聲鯨影；分身可成為反擊與經驗回報的目標。 |
| 深淵幼體 | 轉換為縮小型態並留下深淵污泥，降低移動速度。 |
| 重力支配 | 改變整場水域規則；你必須重新判讀彈射、氧氣與敵人高度。 |
| 氧氣侵蝕 | 氧氣泡會腐化；未及時吸收可能形成爆裂並扣除氧氣。 |

第二章的 Aftermath 會讓氧氣爆裂留下缺氧區域，小怪死亡也可能轉化為氧氣污染；同一套技能因此變成互相放大的逃亡壓力。

## 武器與 Build

### 固定容量：不是把所有東西都升滿

玩家從 Lv.1 開始，固定持有 **小刀 Lv.1**。目前可玩契約是：

- 三個武器槽位、三個被動能力槽位。
- 武器與被動各有四個候選。
- 每一類最多啟用三個。
- 取得順序決定上限：第一個 `Lv.3`、第二個 `Lv.2`、第三個 `Lv.1`。
- 小刀固定佔用第一個武器槽位。
- 在目前契約下，完整 Build 是 Player Lv.1 到 Lv.12，共 11 次升級選擇。

升級流程是：

```text
達到經驗門檻
        ↓
選擇「武器」或「能力」
        ↓
只顯示該類兩個合法選項
        ↓
選一個，更新槽位與等級
        ↓
回到探索
```

已滿槽、已達上限或被規則排除的項目不會被拿來湊無效選項。如果某一類已沒有合法項目，升級畫面只提供另一類；兩類都完成時，代表 Build 滿級。

### 四把武器

| 武器 | Lv.1 | Lv.2 | Lv.3 |
| --- | --- | --- | --- |
| 小刀 | 移動路徑造成傷害。 | 兩側追加傷害軌跡，傷害為主傷害的 70%。 | 停止時持續造成範圍傷害。 |
| 三叉戟 | 高傷害單發遠程攻擊，只在靜止時發射。 | 命中造成暈眩，使敵人停止移動與攻擊。 | 命中後縮短下一次冷卻。 |
| 武士刀 | 自動對約兩個六邊形 Cell 內的近距離敵人揮擊；半徑內每個有效敵人各受一次傷害。 | 每次完成移動後，下一次斬擊雙倍傷害；不移動不會取得強化。 | 追加沿揮刀方向飛出的劍氣，可摧毀敵方子彈。 |
| 輕量機槍 | 射擊期間方向固定的六連射，結束後冷卻。 | 後三發使用高辨識度描邊彈，仍是固定方向六連射。 | 六發各用不同稜彩顏色，提升彈道辨識，不憑空增加範圍爆炸。 |

小刀永遠在 Build 裡；其餘三把武器最多選兩把，因此是「四把定義、三把啟用」。武士刀是繞潛水員軸心的瞬間近戰弧斬，不是把小刀的移動軌跡換成另一個顏色；輕量機槍則是一次鎖定方向的六發射擊，不會在射擊中偷偷追蹤目標。

### 四種被動能力

被動能力不新增按鍵，也不取代武器輸出；它們改變你的氧氣、體力、生命、續航與水域機動方式。

| 能力 | 主要處理的問題 | 適合的風格 |
| --- | --- | --- |
| 氧循環器 | 氧氣消耗、補給與長距離探索。 | 續航、遠路線、高風險氧氣點。 |
| 潮壓穩定器 | 瞄準、發射與擊殺續航。 | 穩定出手、體力循環、節奏型戰鬥。 |
| 生態甲殼 | 遠程傷害與補給轉生命。 | 容錯、生存、把資源轉成 Health。 |
| 深淵增幅器 | 武器傷害與清場速度。 | 純輸出、快速處理、較高風險回報。 |

能力的原則是：讓你做出不同決策，不是無條件取消關卡規則。第二章的失重、污染與氧氣稀少，應該讓能力產生新的價值，而不是讓任何一個能力把深海變成平地。

### 你該如何選 Build

- 常常在路上缺氧：先考慮氧循環器，再挑一把不要求長時間停留的武器。
- 常常瞄準太久或連射斷節奏：潮壓穩定器能把體力變成更穩定的出手機會。
- 還不熟敵人彈幕：生態甲殼的容錯通常比純傷害更能延長一回合。
- 已經能穩定找到氧氣，想縮短 Boss 戰：深淵增幅器才會把你的風險轉成清場收益。

## 檢查點、死亡與復原

### Checkpoint 會做什麼

接觸並啟用 Checkpoint 後：

- 它會成為死亡後的最近返回點。
- 生命、氧氣與體力回滿。
- 永久命數不會增加。

這是讓你能重新練習下一段路線的節點，不是把整趟回合的代價清零。

### 失敗條件

以下兩種情況都會扣一條命：

- Health 歸零。
- 氧氣歸零。

尚有命數時，回到最近 Checkpoint 並恢復基本資源；三條永久命都用完後，這一回合永久死亡，需要重新開始。

### 死亡後的檢討順序

不要只問「我被誰打死」。按這個順序回看：

1. 我是否在沒有確認下一個氧氣點的情況下連續長距離彈射？
2. 我是否為了撿經驗光點，走進不值得的危險？
3. 我是否在錯誤的重力 Cell 裡使用了原本的瞄準習慣？
4. 我是否把 Boss 房的側路氧氣當成了中央補給，沒有預留回程？
5. 我是否有新的武器或被動能讓這段路的風險變得合理？

## 兩章的關卡流程

### 第一章：下沉篇（Descent）

第一章的世界仍維持著脆弱平衡。生物守護自己的領域，水域重力與氧氣來源仍然可以被學習與預測。

```text
入口
  ↓
深海森林
  ↓
熱泉
  ↓
深淵遺跡（下沉狀態）
  ↓
Mini Boss A
  ↓
Mini Boss B
```

第一章的功能不是只把敵人逐步變強，而是讓你學會：

- Lv.1 生物如何建立基本信心。
- Lv.2 核心小怪如何要求你觀察攻擊模式。
- Lv.3 精英如何用特殊機制改變整個戰場。
- 托里切利空間為什麼要放在需要折返的危險路線。
- 你為什麼要在取核前保存足夠的資源與 Build。

### 第二章：上浮篇（Ascent）

你拔出核心後，封住海底裂口的傷口重新打開。上浮篇不是把第一章倒放，而是同一個世界在受傷後留下的反應。

```text
深淵遺跡（上浮狀態）
  ↓
海溝
  ↓
珊瑚區
  ↓
淺海
  ↓
Mini Boss C
  ↓
Mini Boss D
  ↓
Final Boss：深淵抹香鯨
  ↓
帶著深淵核心抵達海面
```

第二章的設計是「對稱但不重複」：

- 減少友善物件，讓氧氣來源更像稀薄的生態痕跡。
- 保留 Lv.2 四種核心小怪，因為它們是原本世界最穩定的戰鬥生態。
- 移除 Lv.1 教學型小怪，表示世界已經不再提供溫柔的學習環境。
- 讓第一章精英以 Lv.4 變異版本回來。
- 增加裂殖燈籠魚與珊瑚背海馬兩種新的特殊生命。
- 讓 Boss 技能保留原本的形狀，但留下缺氧區、污染、重力與敵人死亡的連鎖後果。
- 用多個「高風險路徑換穩定氧氣」的節點支撐長時間上浮，而不是把補給放在正中央。

玩家應感覺到的不是「第二章數值比較大」，而是：

> 這個世界病了，而且它正在用原本維持生命的規則追殺你。

## 整個故事在講什麼

### 世界的傷口

人類曾擁有高度科技，並與未知文明發生戰爭。未知文明將一枚名為 **Abyss Core／深淵核心** 的隕石投入海溝最深處，封住地殼最大的裂口。

那個裂口不是單純的地質洞穴。它是地球海洋生命循環的一部分：微生物、熱泉與化學循環在那裡維持著深海的生命基礎。深淵核心封住裂口後，卻持續放出會改寫演化的輻射：藻類死亡、製氧生態崩潰，世界逐漸失去呼吸。

核心也干擾 AI、機器人、潛艇與智慧機械。只有有生命的神經系統，能穿過核心的共鳴邊界。

### 主角不是英雄

主角是深海盜賊，也是代替人類償還債務的謝罪者。這個角色不是要用英雄姿態拯救海洋，而是承認人類曾經造成的代價，親自走進只有肉身能穿過的深處。

下沉篇的目標是：

1. 穿過仍然維持平衡的深海生態。
2. 抵達核心與古代遺跡。
3. 親手拔出封住裂口的深淵核心。

但拔出核心不等於獲得原諒。核心一離開，裂口重新打開，壓力、污染與變異能量噴發；深海之王甦醒，世界開始以更劇烈的方式失衡。

上浮篇的目標是：

1. 帶著核心離開崩潰源頭。
2. 面對原本的生態變成變異與污染的後果。
3. 在氧氣、重力、Boss 與路線都不再可靠的情況下抵達海面。

你不是把氧氣帶下去拯救海洋的人。你要把那顆讓海洋忘記呼吸的心臟，親手拔出來，再承擔拔出它之後的世界。

> 真正拯救海洋的方法，不是把氧氣帶下去，而是把那顆讓海洋忘記呼吸的心臟，親手拔出來。

### 三張開場故事卡

| 頁面 | 畫面 | 你應該理解的事情 |
| --- | --- | --- |
| 01 | 氧氣崩潰，海洋生態逐漸停止。 | 這不是一個城市或一片海域的事故，而是整個世界正在慢慢停止呼吸。 |
| 02 | 海溝深處的 Abyss Core，生命循環向外共鳴；機械探針停在邊界。 | 機械無法靠近核心，因為這片海拒絕鋼鐵。 |
| 03 | 肉身潛水員與核心訊號連線，舊機械沉在身後。 | 只有活著的肉身能穿過共鳴；你必須親自完成這份任務。 |

### 故事的情緒曲線

| 階段 | 玩家感受 | 世界聲音與視覺 |
| --- | --- | --- |
| 下沉 | 陌生、敬畏、逐漸理解真相。 | 古老、完整、規律、仍在運作的生命循環。 |
| 拔出核心 | 震動、失去平衡、無法回頭。 | 像一顆被拔出的心臟或斷裂的聲學結構。 |
| 上浮 | 緊迫、失控、愧疚、想活著離開。 | 同一套聲音母題失諧、缺拍、破碎回聲、不穩定呼吸。 |

## 聲音、視覺與 HUD 如何幫你讀懂世界

### 古文明聲學工程

聲音的核心風格不是現代科幻，也不是英雄式交響樂，而是：

> 石雕、貝殼、骨質結構與海水共同形成的遠古聲學系統。

| 視覺語言 | 聽覺語言 |
| --- | --- |
| 幾何結構 | 規則脈衝、重複音程、清楚節拍。 |
| 工程草圖 | 不完整音句、可聽見的線條感、保留空白。 |
| 仿生學 | 呼吸、低頻叫聲、甲殼碰撞、生物摩擦。 |
| 石雕與侵蝕 | 厚重低頻、空洞共鳴、石材碰撞與裂解。 |
| 青藍螢光 | 稀有晶體泛音、短促高頻脈衝。 |
| 功能即造型 | 每個聲音都要讓你理解攻擊、警告或狀態。 |

聲音有三個 Phase 母題：

1. **沉睡與探測**：稀疏短句、單次呼吸、微弱石質敲擊。
2. **共生與壓力**：多個短脈衝互相回應，Boss 版本變成儀式性多層節奏。
3. **核心與失衡**：缺拍、斷裂泛音、短暫失控；Boss 版本像整個區域被核心控制。

下沉篇的音程完整、脈衝規律、回聲乾淨；上浮篇保留同一套母題，但加入失諧、缺拍、破碎回聲與不穩定呼吸。你聽到的不是另一個世界，而是同一個世界正在病變。

### HUD 與首次接觸卡

HUD 的優先順序是：

```text
生命／氧氣／體力與戰鬥焦點
        ↓
當下危險與路線判讀
        ↓
首次接觸的敵人、機關或物件說明
        ↓
故事與風味資訊
```

戰鬥畫面一次最多顯示一張首次接觸資訊卡；其他內容排隊，離開視野的目標會暫時移出。整張卡片都是關閉熱區，不要求你精準點擊右下角的 `OK`。同一遊玩 session 內已實際顯示過的介紹不會反覆遮住戰鬥焦點。

這份 Markdown 教學的存在，是讓你在戰鬥外一次讀完規則；遊戲內的資訊卡則只在你第一次遇到對應物件時給最短提醒。

## 圖鑑、地圖編輯器與 GDD 公開索引

主頁的「世界圖鑑」提供敵人、地圖元素、武器、被動能力與共鳴資料的快速入口。想看生物輪廓、技能原型與素材狀態，可以從圖鑑進入；想理解設計為什麼這樣組合，則回到 GDD 原文。

### 地圖是六邊形 Tile Editor

整張地圖不是把圖塊貼成背景，而是讓所有遊戲規則附著在六邊形網格上：

| 層級 | 放什麼 | 例子 |
| --- | --- | --- |
| Cell | 六邊形本身的地形與水域重力。 | `L3`、`L2`、`L1`、`L0`、`L-1`、不可通行區。 |
| Cell Overlay | 覆蓋一格或一片區域的環境效果。 | 珊瑚安全區、墨水區。 |
| Cell Object | 位於 Cell 面上的自由定位物件。 | 地雷、重石、水草、氧氣來源、Checkpoint、按鈕。 |
| Edge | 兩個相鄰 Cell 之間的互動。 | 彈簧水母、尖刺、潮流。 |
| Actor | 依附 Cell 行動的動態角色。 | 玩家、小怪、Mini Boss、Final Boss、出生點。 |

放置語意也不同：水域規則採 **Cell Snap**，整格覆蓋；一般物件採 **Free Snap**，可以在畫布上自由定位；邊緣互動採 **Edge Snap**，只能吸附到共用邊。這些差異就是為什麼托里切利空間可以放在轉彎側角，而不必被迫塞在 Cell 正中央。

目前尚未完全定義、應由驗證器提醒而不是由編輯器擅自猜測的例子包括：珊瑚與墨水是否能重疊、同一格能放幾個氧氣來源、同一條 Edge 能否同時有多種互動，以及 Boss 出生點與其他物件的互斥規則。

### GDD 來源分區

這份教學是給玩家閱讀的公開整合版；完整細節仍保留在以下 GDD 分區：

| 分區 | 內容 |
| --- | --- |
| `GDD/01_願景` | 高概念、核心摘要、核心特色、設計支柱、玩家體驗、美術方向。 |
| `GDD/02_核心玩法` | 玩家操作、核心循環、物理彈射、水域重力、移動風險與報酬。 |

## 版本註記：已確定與仍在調整的部分

### 目前可直接拿來玩的結構性規則

- 以拖曳方向與距離決定彈射初速度。
- 水域重力在 Cell 上持續作用；`L3` 到 `L-1` 五級規則可被關卡配置。
- 氧氣是固定約 40 秒的核心生存資源。
- 光合作用氣泡約回復 50 O₂ 並暫時免疫重力。
- 清氧氣泡回復 25 O₂，Boss 遭遇中會依時間重新生成。
- Boss 房至少有一個位於轉折、上方或側路的常駐托里切利空間。
- Health 為 0–100、初始三條永久命，死亡返回最近 Checkpoint。
- 小刀固定起始；目前完整 Build 為 Lv.1 到 Lv.12，共 11 次選擇。
- 武器、被動、敵人與地圖物件的數值集中在可調整資料模組，方便遊玩測試後調整。

### GDD 中刻意保留的未定義內容

有些文件是設計方向、素材規格或候選提案，不應被這份玩家教學假裝成已完成玩法：

- 某些敵人與 Boss 的最終外觀、素材動畫與完整音效尚在製作。
- 部分 HUD 欄位、鏡頭規則與平台控制配置仍會依測試修訂。
- Actor／出生點的最終吸附規則尚未定案。
- 部分地圖物件的重疊限制與潮流的最終放置層級仍待驗證。
- 結局的呈現方式應保留「人類是否真的償還代價」的餘韻，目前不把它寫成單一明確答案。

### 關於較早的 Lv.13 說法

較早的系統摘要曾寫過 Lv.1 到 Lv.13、12 次選擇；在固定小刀、三個武器槽、三個能力槽與 `Lv.3／Lv.2／Lv.1` 上限被釐清後，現行可玩契約改為 **Lv.1 到 Lv.12、11 次選擇**。這份教學跟隨目前的固定小刀規則；若之後要回到 Lv.13，必須新增清楚定義的升級類型，而不是讓小刀重複占用起始選項。

> 以遊戲內 HUD、目前資料模組與實際可玩的規則為優先；GDD 中標記為提案、待補或未定義的內容，會明確保留它的狀態，不把想法冒充成承諾。

## 給第一次下潛的最後一張小抄

```text
先看氧氣，再看路。
先看水域，再拉方向。
先想回程，再碰補給。
先問值不值得，再決定戰鬥。
看到托里切利空間，不要急著衝中央——它通常藏在你必須辛苦走過去的地方。
拔出核心之後，世界不會獎勵你；它會開始追你。
```

你真正要學會的不是「怎麼把潛水員射得更遠」，而是如何在一個會持續改變重力、氧氣與生態的世界裡，讓下一次彈射仍然有意義。
