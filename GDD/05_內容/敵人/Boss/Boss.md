# Final Boss：深淵抹香鯨（原：深海之王；The Abyssal Sovereign）

## 核心定位

**Battlefield Controller（戰場支配者）**

深海之王本身幾乎不依賴普通攻擊，而是透過操控整個戰場來削弱玩家，並藉由小兵、地形與環境建立優勢。

玩家真正的敵人不是 Boss 本體，而是 Boss 所創造出的戰場。

深海之王是守護海洋平衡與深淵核心的沉睡守護者。主角拔出核心後，海底裂口重新打開，深海之王甦醒並追擊帶走核心的謝罪者。因此 Boss 的戰鬥行為應該像世界對傷口的反應，而不是單純的輸出型敵人。

## Passive：深淵覺醒（Abyss Awakening）

當生命值低於 50% 時，深海之王進入全面進攻狀態：

- 移動速度提升。
- 子彈速度提升。
- 技能冷卻降低。
- 全體召喚物獲得能力強化。
- 獲得荊棘護甲（Thorns）；玩家與 Boss 接觸或以近戰命中時受到反傷。

第二階段代表深海之王不再防守，而是主動接管戰場。

## Skill 1：深海召令（Abyssal Summoning）

固定時間召喚一波小兵。

### 召喚內容

- 該章節登場的所有種類小怪皆可能出現。

### 獻祭規則

召喚 30 秒後，若仍有小兵存活：

- 全部小兵被獻祭。
- Boss 回復一定比例生命。
- Boss 獲得攻擊力提升；增益可疊加或成為短時間增益，實際形式待平衡測試確認。

### 設計目的

這不是單純拖延時間，而是要求玩家必須清場。玩家若放任召喚物存活，就會把戰場資源轉化為 Boss 的續戰力與輸出壓力。

## Skill 2：遺跡重現（Ancient Reconstruction）

深海之王重建一段該章節的地形，將戰鬥轉為短暫的防守關卡。

### 效果

- Boss 躲藏於重建地形後方。
- 玩家鏡頭固定於戰鬥區域。
- 場內出現敵人與持續回血裝置。
- 玩家必須清除所有敵人，才能解除重建狀態。
- 重建期間 Boss 持續恢復生命。
- 當 Boss 再次進入畫面時，回血裝置停止。

### 設計目的

讓玩家短暫離開直接攻擊 Boss 的節奏，改為處理敵人、地形與視野限制。這是 Boss 對既有關卡記憶的重新支配。

## Skill 3：深淵化身（Abyss Echo）

召喚兩具大型深淵分身。

### 分身特性

- 緩慢下降。
- 高生命值。
- 持續發射簡單彈幕。

### 反擊機制

分身每次受到攻擊時，立即向攻擊者方向發射反擊子彈。

這不是直接反傷，而是可被觀察、躲避與利用位置處理的反擊彈幕。

### 擊破收益

- 掉落生命。
- 掉落經驗。

### 設計目的

高頻武器可以快速清理分身，但也會更頻繁地觸發反擊彈幕，因此清理速度越快，短時間承受的風險也越高。

## Skill 4：深淵幼體（Miniature Form）

深海之王縮小自身，從戰場控制者轉為高速追擊者。

### 效果

- Boss 所受傷害增加 20%。
- 移動速度大幅提升。
- 技能冷卻降低 50%。
- Boss 移動路徑留下深淵污泥。

### 深淵污泥

深淵污泥大幅降低玩家移動速度，使玩家更難脫離 Boss 的追擊與後續戰場效果。

### 設計目的

讓 Boss 的戰鬥身份產生明確轉換：從「控制者」變成「追擊者」。玩家必須利用 Boss 受傷增加的弱點換取輸出窗口，同時承受更高的機動壓力。

## Skill 5：重力支配（Gravity Dominion）

深海之王操控整片水域，直接改變玩家對整張地圖的理解。

### 效果

- 上浮／下沉方向切換。
- 所有水域的 `gravityLevel` 提升 1 級，最高限制在 `L3`。

### 水域變化例

```text
淺色（L-1） → 中性色帶（L0）
中性色帶（L0） → 一般藍色（L1）
一般藍色（L1） → 深藍過渡帶（L2）
深藍過渡帶（L2） → 深色（L3）
深色（L3） → 深色（L3，上限）
```

「上浮／下沉方向切換」是獨立於等級提升的方向覆寫；等級提升只改變當前水域加速度的層級，不重設玩家速度。

### 設計目的

這不是單一攻擊，而是全場規則變更。玩家必須重新判讀彈射路徑、水域位置、氧氣來源與敵人所在高度。

## Skill 6：氧氣侵蝕（Corrupted Oxygen）

深海之王召喚大量氧氣泡，將補給品轉化為限時戰場機制。

### 效果

- 玩家可以吸收氧氣泡，恢復氧氣。
- 未被吸收的氧氣泡會逐漸腐化。
- 腐化完成後形成氧氣爆裂。
- 氧氣爆裂造成大範圍爆炸，並扣除玩家氧氣。

### 設計目的

玩家不能把氧氣泡單純視為安全補給，而必須在「現在吸收」與「繼續處理 Boss／敵人」之間做出決定。Boss 將玩家最依賴的生存資源反過來變成戰場壓力。

## 戰鬥設計總結

深海之王的技能共同服務於「掌控整個戰場」：

| 技能 | 被支配的戰場層 | 玩家被要求處理的問題 |
| --- | --- | --- |
| 深海召令 | 敵人數量與時間 | 是否能在獻祭前清場 |
| 遺跡重現 | 地形、視野與防守區域 | 是否能清除敵人並解除回血 |
| 深淵化身 | 分身與反擊彈幕 | 輸出速度與反擊風險的取捨 |
| 深淵幼體 | Boss 追擊路徑 | 如何在減速區中保持距離 |
| 重力支配 | 全地圖移動規則 | 如何重新判讀彈射與水域 |
| 氧氣侵蝕 | 生存資源與補給時間 | 何時吸收氧氣、何時承受爆裂風險 |

Boss 的威脅不應只由傷害數值提供，而應由玩家同時需要管理的戰場狀態數量提供。

## 第二章變異版：上浮篇 Aftermath Buff

第二章不新增 Final Boss 技能。深海之王仍然使用同一組「深淵覺醒」與六個戰場控制技能，但每個技能都會留下更長時間的後果，並開始與其他技能互相連動。

第一章的戰鬥哲學是：

> 每個技能各自建立一種戰場壓力。

第二章的戰鬥哲學是：

> 技能本身沒有改變，但它們開始互相影響、互相強化，讓整個戰場逐步失去平衡。

### Passive：深淵覺醒（強化）

保留第一章效果：

- 二階段提升移動速度、子彈速度與技能頻率。
- 全體召喚物獲得能力強化。
- Boss 擁有荊棘護甲，接觸或近戰命中會造成反傷。

新增 Aftermath：

- Boss 每擊殺一隻小兵，永久提升自身 1% 攻擊力。
- 攻擊力永久增益的上限需由平衡測試設定。

這使小兵不只是玩家必須處理的壓力，也是 Boss 的戰鬥資源。玩家需要留意哪些小兵可能被 Boss 或戰場效果擊殺，而不是只看小兵是否靠近自己。

### Skill 1：深海召令（強化）

保留第一章規則：召喚 30 秒後，仍存活的小兵會被獻祭，Boss 回復生命並獲得攻擊力增益。

新增 Aftermath：

- 每隻被獻祭的小兵，會把一個生前能力轉移給 Boss。
- 轉移效果持續 20 秒。
- 多個同類能力是否能疊加，交由平衡測試確認。

能力繼承例：

| 被獻祭的小兵 | Boss 繼承的能力 |
| --- | --- |
| 戰士型小怪 | 碰撞傷害增加 |
| 射手型小怪 | 子彈數量增加 |
| 精英型敵人 | 技能範圍增加 |

玩家因此必須開始選擇先擊殺哪一種小怪，而不是只追求最快清除總數。

### Skill 2：遺跡重現（強化）

保留第一章規則：Boss 躲在重建地形後回血，玩家必須清除敵人才能解除防守狀態。

新增 Aftermath：

- Boss 每回復一次指定比例的生命，遺跡就逐步修復。
- 修復會永久改變本次 Boss 戰的場地，直到戰鬥結束。

遺跡修復例：

- 多一道牆。
- 多一個重力區。
- 多一段潮流。

拖延越久，下一次面對 Boss 時的地圖就越難。回血不再只是恢復生命，而是持續增加戰場複雜度。

### Skill 3：深淵化身（強化）

保留第一章規則：召喚兩具大型分身，受到攻擊時向攻擊者發射反擊子彈。

新增 Aftermath：

- 兩具分身共享同一個生命池。
- 任一分身受到攻擊時，另一具分身同步發射反擊子彈。
- 玩家若持續攻擊同一具分身，另一具分身會持續支援。

玩家不能再把兩具分身視為兩個獨立目標，而必須觀察兩者的距離、反擊方向與共同生命狀態。

### Skill 4：深淵幼體（強化）

保留第一章規則：Boss 縮小、移動速度大幅提升、技能冷卻降低，並在路徑上留下深淵污泥。

新增 Aftermath：

- 深淵污泥存在一段時間後，會孵化出 Lv.1 小怪。
- 污泥的持續時間與孵化時間需由平衡測試確認。

Boss 經過的地方會逐漸變成危險區。玩家若只顧著逃離 Boss，可能會把追擊路徑轉化成下一輪小怪的出生區。

### Skill 5：重力支配（強化）

保留第一章規則：Boss 能切換上浮／下沉方向，並改變水域重力。

新增 Aftermath：

- 重力不再只被改變一次，而是進入週期性震盪。
- 基準提案為每 5 秒切換一次重力狀態。
- 震盪序列可依序經過：深色（L3）→ 深藍過渡帶（L2）→ 一般藍色（L1）→ 中性色帶（L0）→ 淺色（L-1）。
- 切換時間、狀態順序與是否循環，交由平衡測試確認。

玩家不能只適應一次重力變更，而必須持續重新判讀彈射路徑、敵人位置、氧氣泡方向與污泥分布。

### Skill 6：氧氣侵蝕（強化）

保留第一章規則：未被吸收的氧氣泡會腐化並形成氧氣爆裂，造成大範圍爆炸與氧氣損失。

新增 Aftermath：

- 每次氧氣爆裂後，在爆炸位置留下缺氧區域。
- 玩家停留在缺氧區域時，每秒扣除氧氣。
- 缺氧區域持續 10 秒。
- 缺氧區域的範圍與每秒扣除量需由平衡測試確認。

玩家不能只躲過一次爆炸；爆炸會把戰場的一部分永久轉化為短時間的污染區。

## 第二章全體連鎖效應

第二章的隱藏核心效果是：所有技能開始共享戰場狀態。

| 來源效果 | 連動結果 |
| --- | --- |
| 重力支配 | 氧氣泡的漂浮／移動方向同步改變 |
| 深淵幼體 | 深淵污泥可被潮流推動，污染路徑因此持續移動 |
| 遺跡重現 | 深淵化身可生成在重建地形後方，迫使玩家處理視線與位置關係 |
| 小兵死亡 | 有機率轉化為氧氣污染，增加腐化氧氣泡或缺氧區域壓力 |
| 深海召令 | Boss 繼承的小兵能力會強化後續重力、彈幕或追擊階段 |
| 遺跡修復 | 新增的牆、重力區與潮流會改變所有其他技能的行走與彈射路徑 |

這些連鎖效果不是新的技能按鈕，而是第二章世界崩壞後，原本分開的系統失去隔離。玩家面對的將不再是「Boss 施放了哪個技能」，而是「這個技能會讓整個戰場接下來變成什麼樣子」。
