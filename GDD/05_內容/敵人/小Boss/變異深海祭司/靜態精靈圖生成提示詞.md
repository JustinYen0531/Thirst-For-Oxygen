# 靜態精靈圖生成提示詞：變異深海祭司

以下提示詞可直接搭配同一張角色參考圖使用。這裡生成的是一張張可切出的靜態 sprite，不是影片，也不是連續動畫檔。

## 固定前綴

```text
使用提供的「變異深海祭司」角色參考圖，完整保留角色原本的生物形體、古文明工程草圖、幾何仿生、深海石雕、侵蝕紋理、裝甲比例與青藍發光裂紋。生成一張 1536×1024 的 3×2 六格精靈圖，每格等大、每格只有一張完整靜態角色圖，固定三分之二側面視角，角色朝左，角色高度與中心位置完全一致，純螢光綠背景，無紋理、無漸層、無地面、無投影、無文字、無 UI、無玩家、無其他角色。六格之間只能改變姿勢與動作，不得改變角色設計。
```

## 共用本體圖組

沿用原型角色的共用本體圖組，不重新設計身體。請使用原型參考圖，維持相同的待機、移動、受擊與死亡姿勢；只在需要時加入變異結晶與發光覆蓋。

## 特殊機制圖組

```text
護盾啟動、受到傷害、傷害轉化生命、散彈轉化護盾、雙重法則啟動、法則重疊。每一格必須是清楚、可分辨、可以單獨切出的靜態 sprite。動作要保留「準備／蓄力 → 施放／作用 → 收招／結果」的視覺因果，不要使用會遮住角色輪廓的強烈動態模糊。
```

## 特效分離提示

```text
只生成與「變異深海祭司」特殊機制對應的獨立透明感特效參考圖：保留清楚的形狀、方向與大小，不出現角色、不出現場景、不出現文字。特效包括該敵人技能需要的彈體、爆炸、漣漪、能量線、標記、結晶或環境污染；每個效果仍使用 3×2 六格、六張靜態圖。
```

## 負面限制

```text
不要改變角色物種、臉部、肢體數量、裝甲、武器、視角、朝向、比例或配色；不要生成影片畫格、背景場景、地面陰影、文字、標籤、血條、玩家、第二隻角色或重複肢體。
```
