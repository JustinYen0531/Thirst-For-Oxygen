# 靜態精靈圖預覽入口

> 這是目前所有非 Boss 角色的 GIF 驗收入口。直接在 Markdown 預覽中往下看，即可逐組檢查動作；Boss／小 Boss 不在此入口。

目前共 **14 個角色、86 組 GIF 預覽**。每組 GIF 對應同名的獨立 PNG 幀序列。

> 預覽節奏已調慢為原本的 3 倍：每幀停留時間為 240／360／420 毫秒（依各組原始設定而定）。PNG 幀沒有被修改。

## 使用方式

- 先看每個角色的 `base-float-move`，確認本體中心與比例。
- 再看 `hit`、`death` 與技能組；角色本體不應突然跳位。
- `projectile`／`effect` 是獨立素材，只驗收效果形狀與可調整性。
- 共用規格：[靜態精靈圖生成總規格](靜態精靈圖生成總規格.md)。
