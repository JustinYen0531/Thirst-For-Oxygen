# 敵人

## 目錄結構

本資料夾集中收納所有敵人、Mini Boss 與 Final Boss。根目錄只放跨分類的總覽、配置、靜態精靈圖與生成規格；單一敵人依照角色類型或等級放入下方子資料夾，每個敵人資料夾內再分開保存戰鬥設計、靜態精靈圖需求與生成提示詞。

| 資料夾 | 內容 |
| --- | --- |
| [Boss](Boss/) | Final Boss：深淵抹香鯨與 Boss 結構 |
| [小Boss](小Boss/) | Mini Boss、變異 Mini Boss 與配置 |
| [等級1](等級1/) | Lv.1 教學型小怪 |
| [等級2](等級2/) | Lv.2 核心小怪 |
| [等級3](等級3/) | Lv.3 下沉篇精英小怪與上浮篇新小怪 |
| [等級4](等級4/) | Lv.4 變異小怪與上浮篇變異精英 |

## 根目錄文件

- [敵人配置](敵人配置.md)：章節中的敵人數量、等級與變化。
- [世界圖鑑](敵人圖鑑.md)：敵人／Boss 的動物原型、地圖元素、武器與被動能力的共同內容入口；本文件的敵人區仍保留 Level 1–4、Mini Boss 與 Final Boss 資料。
- [靜態精靈圖需求總覽](靜態精靈圖需求總覽.md)：所有敵人的靜態精靈圖工作入口與共用規格。
- [敵人生成提示詞](敵人生成提示詞.md)：依圖鑑設定整理的角色生成提示詞。
- [靜態精靈圖生成總規格](靜態精靈圖生成總規格.md)：所有敵人靜態 sprite 圖組的共同生成規格。
