# 敵人

## 目錄結構

本資料夾集中收納所有敵人、Mini Boss 與 Final Boss。根目錄只放跨分類的總覽、配置、動畫與生成規格；單一敵人依照角色類型或等級放入下方子資料夾。

| 資料夾 | 內容 |
| --- | --- |
| [Boss](Boss/) | Final Boss：深海之王與 Boss 結構 |
| [小Boss](小Boss/) | Mini Boss、變異 Mini Boss 與配置 |
| [等級1](等級1/) | Lv.1 教學型小怪 |
| [等級2](等級2/) | Lv.2 核心小怪 |
| [等級3](等級3/) | Lv.3 特殊小怪 |
| [等級4](等級4/) | Lv.4 變異小怪與變異精英 |
| [精英](精英/) | 尚未納入 Lv.1～Lv.4 分級的精英個體 |

## 根目錄文件

- [敵人配置](敵人配置.md)：章節中的敵人數量、等級與變化。
- [敵人圖鑑](敵人圖鑑.md)：所有單一敵人的索引。
- [敵人動畫需求](敵人動畫需求.md)：第一檔敵人動畫與必要特效清單。
- [敵人生成提示詞](敵人生成提示詞.md)：沿用海馬設計語言的角色生成提示詞。
- [敵人動畫生成提示詞](敵人動畫生成提示詞.md)：以兩張關鍵幀圖製作敵人動畫的生成規格。
