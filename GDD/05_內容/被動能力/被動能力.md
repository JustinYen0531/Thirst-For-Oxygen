# 被動能力

被動能力是玩家升級 Build 時選擇的持續效果。它們不取代武器的主動攻擊，而是改變玩家如何移動、管理資源與判斷戰場。

玩家最多啟用三個能力；第一個取得的能力最高 Lv.3，第二個最高 Lv.2，第三個固定 Lv.1，第四個不進入 Build。

## 能力總覽

| 能力 | Build 方向 | 核心改變 |
| --- | --- | --- |
| [壓縮氧氣囊](壓縮氧氣囊.md) | 氧氣路線 | 將氧氣來源轉化為可安排的額外發射機會 |
| [節奏呼吸](節奏呼吸.md) | 體力節奏 | 讓飛行、休息與水草附著互相接續 |
| [慣性記憶](慣性記憶.md) | 物理機動 | 記住碰撞結果，讓反彈可以被納入下一次路線 |
| [獵潮感知](獵潮感知.md) | 戰場判讀 | 讀取敵人的攻擊預兆，利用失衡控制戰鬥節奏 |

## 與武器的關係

- 小刀仍然負責「移動路徑造成傷害」。
- 武士刀仍然負責「近距離停留與斬擊」。
- 三叉戟仍然負責「靜止時的高傷害單發攻擊」。
- 輕量機槍仍然負責「固定方向的連續射擊」。

被動能力只改變玩家取得輸出位置的方式，以及為了取得該位置需要承擔的風險。
