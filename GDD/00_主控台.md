## 遊戲摘要

玩家扮演一名潛入深海竊取秘寶的小偷，在取得寶藏後意外喚醒沉睡於深海的守護者——深海之王。玩家必須一邊躲避追擊，一邊利用有限的氧氣向海面逃亡。

主角不是英雄，而是謝罪者。人類曾經在戰爭中摧毀海洋的生命循環；如今，主角必須以肉身深入世界最深的海溝，拔出讓海洋忘記呼吸的深淵核心。核心被拔出後，封住海底裂口的傷口重新打開，世界開始真正崩潰，逃亡才正式開始。

第一部分的故事入口採用三張深海示意圖與底部 Narrator 打字框：先讓玩家看見氧氣崩潰、Abyss Core 與肉身謝罪者，再接回既有 HUD、閘門與航程節點 1 的入口演出。完整投影片、旁白與互動規則見[願景核心摘要](01_願景/核心摘要.md)與[玩家體驗](01_願景/玩家體驗.md)。

## 核心設計支柱

1. 氧氣同時是移動成本與生存壓力。
2. 物理彈射讓移動具有風險與不可完全預測性。
3. 水域環境會改變玩家的移動規則。
4. 戰鬥與 Roguelike Build 支援玩家突破上升路線。
5. Checkpoint 與 Boss 將逃亡旅程切成階段。

## 核心循環

探索 → 利用彈射移動 → 消耗氧氣與體力 → 收集氧氣 → 擊敗小怪 → 獲得經驗 → 升級 Build → 擊敗 Boss → 解鎖下一區 → 持續向海面逃亡

## 故事服務設計

| Lore 核心 | 服務的設計 | 運用方式 |
| --- | --- | --- |
| 深淵核心堵住生命循環源頭 | 海溝、遺跡、世界結構 | 讓海溝成為故事與關卡的共同核心，不只是一個最深的地點 |
| 核心改寫演化、讓海洋慢性缺氧 | 氧氣系統、氧氣來源、敵人變異 | 氧氣是正在消失的生態資源；敵人變異是污染後果 |
| 只有生命能與核心共鳴 | 主角、肉身操作、生命／死亡 | 說明為什麼不能用機器代替主角，並讓生存系統具有敘事重量 |
| 主角是謝罪者 | 玩家體驗、兩章情緒、結局語氣 | 不把主角包裝成征服者；讓每次前進都帶著代價與責任 |
| 拔出核心後傷口打開 | 世界變異、上浮篇、難度曲線 | 第二章的危險來自世界崩潰，而不是單純數值升高 |
| 深海之王是沉睡守護者 | Boss 結構、聲音、追擊壓力 | 將 Final Boss 設計成守護與反應，不只是邪惡反派 |
| BUDDY 是人與海洋的關係 | Resonance、敵人中立化、跨篇章情緒 | 玩家可以不殺死生物，靠共鳴取得本回合永久 Buff；上浮篇不保留下降篇武器，但保留一路培養的羈絆 |
