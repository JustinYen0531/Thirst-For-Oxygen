# 武器系統

武器主要影響主動輸出方式。目前共有四把武器，但單次 Build 最多啟用三把；玩家固定從 **Lv.1 小刀** 開始，小刀永遠佔其中一個槽位。

目前武器內容請見 [05_內容/武器](../05_內容/武器/)。

## Build 槽位

小刀先佔用主武器槽位；玩家再依取得順序把最多兩把額外武器放入剩餘槽位：

| 槽位 | 最高等級 | 意義 |
| --- | ---: | --- |
| 主武器 | Lv.3 | 主要輸出核心 |
| 副武器 | Lv.2 | 補足輸出或處理特定敵人 |
| 副副武器 | Lv.1 | 提供一次基礎戰術功能 |

未被選中的其餘武器不會進入 Build。當三個槽位填滿後，剩餘候選永久離開升級選項池；當副槽已達 Lv.2、副副槽已取得 Lv.1 後，對應武器也不再出現無效升級選項。

升級時玩家先選擇武器分支，再從兩個合法武器選項中選一個。完整的 11 次升級分配與二選一流程見 [成長與 Build 系統](成長與Build系統.md)。
