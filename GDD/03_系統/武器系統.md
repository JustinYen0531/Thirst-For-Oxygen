# 武器系統

武器主要影響主動輸出方式。目前共有四把武器，但單次 Build 最多啟用三把。

目前武器內容請見 [05_內容/武器](../05_內容/武器/)。

## Build 槽位

玩家依取得順序將武器放入三個槽位：

| 槽位 | 最高等級 | 意義 |
| --- | ---: | --- |
| 主武器 | Lv.3 | 主要輸出核心 |
| 副武器 | Lv.2 | 補足輸出或處理特定敵人 |
| 副副武器 | Lv.1 | 提供一次基礎戰術功能 |

第四把未選中的武器不會進入 Build。當三個槽位填滿後，第四把武器永久離開升級選項池；當兩把武器已達 Lv.2，剩下的 Lv.1 武器也不再出現升級選項。

升級時玩家先選擇武器分支，再從兩個合法武器選項中選一個。完整的 12 次升級分配與二選一流程見 [成長與 Build 系統](成長與Build系統.md)。
