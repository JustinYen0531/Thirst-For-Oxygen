# 03 系統｜核心摘要

> 系統章負責把核心玩法落成資源、戰鬥、成長與死亡規則；數值尚未完整定義的地方不能自行補成既定規格。

## 先記住

### 玩家資源

- **氧氣**：每次噴射消耗，消耗量受拉力與距離影響；碰觸含氧區域恢復；耗盡時無法噴射且極易死亡。
- **體力**：限制瞄準與發射頻率；發射及瞄準消耗，可透過原地休息或擊殺掉落恢復。
- **生命與命數**：目前確立為三條命；到達 Checkpoint 回滿生命，死亡回到最近已開啟的 Checkpoint。

### 戰鬥與成長

- 玩家可擊敗敵人，也可直接閃避。
- 擊殺主要提供經驗值與體力補充。
- 升級時從多個能力中選一個，逐步形成 Build。
- Build 方向目前以高輸出、高續航、控場、機動為範例。
- 武器負責主動輸出；被動能力負責生存、資源管理與機動，兩者可自由搭配。
- 每個區域的 Boss 是 Build 檢驗點，擊敗後才能繼續上升。

## 系統關係

```text
彈射移動 → 消耗氧氣／體力
氧氣來源 → 支撐下一段移動
敵人 → 戰鬥或閃避的選擇
擊殺 → 經驗／體力
經驗 → Build 選擇
Build → Boss 檢驗
死亡 → 最近 Checkpoint（最多三條命）
```

## 目前未定義

- 生命值的具體規則與傷害計算。
- 被動能力的正式種類。
- 武器、能力、經驗與資源的數值、冷卻與掉落率。
