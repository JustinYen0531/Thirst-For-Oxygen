# 03 系統｜核心摘要

> 系統章負責把核心玩法落成資源、戰鬥、成長與死亡規則；數值尚未完整定義的地方不能自行補成既定規格。

## 先記住

### 玩家資源

- **氧氣**：每次噴射消耗，消耗量受拉力與距離影響；碰觸含氧區域恢復；耗盡時無法噴射且極易死亡。
- **體力**：限制瞄準與發射頻率；發射及瞄準消耗，可透過原地休息或擊殺掉落恢復。
- **生命與命數**：目前確立為三條命；到達 Checkpoint 回滿生命，死亡回到最近已開啟的 Checkpoint。

### 戰鬥與成長

- 玩家可擊敗敵人，也可直接閃避。
- 擊殺主要提供經驗值與體力補充。
- 玩家初始為 Lv.1，完整升級為 Lv.13，共有 12 次升級選擇。
- 每次升級先選擇武器或能力，再從該類兩個合法選項中選一個。
- 武器與被動能力各自最多啟用三個項目，最終分配固定為 Lv.3、Lv.2、Lv.1。
- 武器負責主動輸出；被動能力負責氧氣、體力、生存與重力機動，兩者可自由搭配。
- 每個區域的 Boss 是 Build 檢驗點，擊敗後才能繼續上升。

## 系統關係

```text
彈射移動 → 消耗氧氣／體力
氧氣來源 → 支撐下一段移動
敵人 → 戰鬥或閃避的選擇
擊殺 → 經驗／體力
經驗 → 玩家等級
玩家等級 → 武器／能力二選一
Build → Boss 檢驗
死亡 → 最近 Checkpoint（最多三條命）
```

## 目前未定義

- 生命值的具體規則與傷害計算。
- 武器、能力、經驗與資源的最終數值、冷卻與掉落率。
