# 成長與 Build 系統

## 核心規則

- 玩家初始為 **Player Lv.1**。
- 玩家預設持有 **Lv.1 小刀**；小刀直接佔用第一個武器槽位，不會再透過選項抽取。
- 在目前三個武器槽位、三個能力槽位與 Lv.3／Lv.2／Lv.1 上限下，完整 Build 會從 Lv.1 升到 **Lv.12**，共有 11 次升級選擇。
- 每次升級先選擇「武器」或「能力」其中一類，再從該類顯示的兩個合法選項中選一個。
- 擊敗敵人取得經驗；完整清除可擊敗敵人的路線，才有機會取得全部 11 次升級。
- 玩家可以閃避敵人，但少擊殺會少取得經驗，最終 Build 等級可能低於 Lv.12。

## 經驗值與光點

敵人被擊敗時，依資料中的 `tier` 生成一顆經驗光點。光點固定停留在擊敗位置，不會自動追蹤玩家；玩家必須親自靠近拾取，才會把經驗加入等級進度。

| 敵人層級 | 經驗值 |
| --- | ---: |
| Tier 1 | 14 |
| Tier 2 | 24 |
| Tier 3 | 38 |
| Tier 4 | 58 |
| Mini Boss | 150 |
| 變異 Mini Boss | 220 |
| Final Boss | 600 |

經驗門檻與敵人經驗值都放在可調整資料契約中；達到門檻後遊戲暫停，玩家完成升級選擇後才能繼續探索。

## Build 的固定容量

武器與被動能力各自擁有三個啟用槽位。每一類的最終等級分配固定為：

| 取得順序 | Build 身份 | 最高等級 | 最終用途 |
| --- | --- | ---: | --- |
| 第 1 個取得 | 主槽 | Lv.3 | 主要輸出／主要能力核心 |
| 第 2 個取得 | 副槽 | Lv.2 | 補足主要 Build 方向 |
| 第 3 個取得 | 副副槽 | Lv.1 | 提供一次基礎功能 |

因此：

- 小刀已預設為第一槽 Lv.1；武器剩餘的升級／取得流程消耗 5 次升級。
- 能力最多消耗 3 + 2 + 1 = 6 次升級。
- 全部完成為 5 + 6 = 11 次升級。
- Player Lv.1 + 11 次升級 = Player Lv.12。

## 武器：四選三

目前共有四把武器：

- 三叉戟
- 小刀
- 武士刀
- 輕量機槍

玩家最多啟用其中三把；小刀永遠是其中一把，另外兩把才從其餘三個候選中選入。四把武器定義仍保留，但不會四把同時存在於 Build 中。

### 武器出現規則

1. 遊戲開始時小刀已在主槽 Lv.1，最高升至 Lv.3。
2. 第一把額外取得的武器進入副槽，最高升至 Lv.2。
3. 第二把額外取得的武器進入副副槽，只保留 Lv.1。
4. 當三個武器槽位已填滿，尚未選中的第四把武器永久離開選項池。
5. 當兩把武器已經達到 Lv.2，剩下的 Lv.1 武器不再出現升級選項，維持 Lv.1。
6. 主槽武器完成 Lv.3、或副槽武器完成 Lv.2 後，該武器不再出現。

## 能力：四選三

被動能力使用與武器相同的三槽位規則：

1. 第一次取得的能力進入主能力槽，最高升至 Lv.3。
2. 第二次取得的能力進入副能力槽，最高升至 Lv.2。
3. 第三次取得的能力進入副副能力槽，只保留 Lv.1。
4. 當三個能力槽位已填滿，尚未選中的第四個能力永久離開選項池。
5. 當兩個能力已經達到 Lv.2，剩下的 Lv.1 能力不再出現升級選項，維持 Lv.1。
6. 主能力完成 Lv.3、或副能力完成 Lv.2 後，該能力不再出現。

## 升級選項流程

```text
擊敗敵人 → 取得經驗 → 達到升級門檻
                         ↓
                選擇：武器 或 能力
                         ↓
             顯示該類兩個合法選項
                         ↓
               選擇一個並套用等級
                         ↓
                更新槽位與選項池
```

合法選項只包含：

- 尚未達到該槽位最高等級的已啟用項目。
- 尚未填滿三個槽位時，可新加入的候選項目。
- 尚未被規則鎖定的候選項目。

如果某一類已經沒有合法選項，升級畫面不顯示該類；玩家只能選擇另一類。兩類都完成後，代表 Build 已經滿級。

## 起始武器已確認

玩家一開始固定持有 **小刀 Lv.1**，它是主槽的初始武器，也是玩家唯一不需要透過升級選項取得的武器。升級時仍可選擇提升小刀，或從其餘三把武器中取得最多兩把；能力槽位則維持原本的四選三規則。

## 設計目的

這不是讓玩家把所有東西都升滿，而是讓玩家在有限的 11 次選擇中建立一條清楚的成長路徑。玩家真正決定的是：

- 如何把固定的小刀升成主武器核心，以及要補進哪兩把額外武器。
- 哪一種能力成為核心能力。
- 哪兩個項目被犧牲在 Lv.2 與 Lv.1。
- 是否為了升級而冒險清除更多敵人。

## 平衡備註

目前各級效果與數值是可遊玩版本的初始提案，仍需透過實際測試調整；目前 11 次升級、固定小刀、四選三、三加二加一與選項鎖定規則是本系統的結構性規則。若未來要回到 Lv.13，必須另外增加一種明確的升級類型，不能讓小刀重複占用起始選項。
