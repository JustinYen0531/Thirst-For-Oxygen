# 01 願景｜核心摘要

> 這一頁只保留本作的方向與不可偏離的設計主旨；角色、關卡與系統細節請回到延伸文件。

## 先記住

- **遊戲身份**：玩家以肉身深入深海的謝罪者，不是征服深海的英雄。
- **核心體驗**：在有限氧氣與體力下，以物理彈射穿越不同水域，選擇戰鬥或閃避並建立 Build，持續完成向下取核、向上逃亡的旅程。
- **故事轉折**：第一章「下沉篇」進入仍維持脆弱平衡的深海並拔出深淵核心；第二章「上浮篇」帶著核心逃離一個因傷口重新打開而崩潰的世界。
- **世界主旨**：氧氣不是抽象 UI 數值，而是海洋製氧生態系慢性死亡後所剩的生命資源。

## 開發時不可偏離

1. 氧氣同時是移動成本與生存壓力。
2. 移動依靠物理彈射，落點不應完全可控。
3. 水域會改變重力、浮力或移動狀態。
4. 戰鬥、閃避與 Build 成長都應服務於逃亡選擇，而非單純堆數值。
5. 第二章的危險來自拔出核心的後果，不只是「敵人變強」。
6. 視覺共同語言是古文明工程草圖：幾何、仿生、深海石雕與侵蝕；螢光只作為功能訊號。

## 目前已確立的敘事骨架

```text
人類造成海洋慢性污染
↓
謝罪者以生命與深淵核心共鳴
↓
深入海溝並拔出核心
↓
裂口重新打開，深海之王甦醒
↓
在失衡的世界中帶著核心逃回海面
```

## 目前未在本章定義

- 具體劇情演出、對話與結局呈現方式。
- 氧氣、體力、生命與 Build 的數值。
- 各章節的完整關卡與內容排程。
