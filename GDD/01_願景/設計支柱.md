# Design Pillars

1. 氧氣既是移動資源，也是生存資源。
2. 移動依靠物理彈射，實際落點不完全可控。
3. 不同水域會改變重力、浮力或移動狀態。
4. 玩家可在戰鬥、閃避與 Build 成長之間做選擇。
5. Boss 是每個區域的 Build 檢驗點。

## 故事設計支柱

1. 深淵核心是海洋慢性死亡的根源，不是單純等待被擊敗的魔王。
2. 海溝是地球生命循環的源頭，因此所有深海環境都應與生命、氧氣與演化產生關聯。
3. 主角是謝罪者，不是英雄；行動的代價必須持續存在於玩家體驗中。
4. 生命共鳴是主角能深入海溝並拔出核心的理由，機械失效不能只是背景設定。
5. 上浮篇的失控與變異必須是拔出核心造成的後果，而不是無理由的第二章升級。
