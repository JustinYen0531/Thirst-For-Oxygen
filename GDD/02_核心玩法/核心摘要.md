# 02 核心玩法｜核心摘要

> 這一頁回答「玩家如何移動、如何做取捨，以及一輪遊戲如何前進」。

## 先記住

核心循環是：

```text
探索 → 彈射移動 → 消耗氧氣與體力 → 找到氧氣 → 擊敗或閃避敵人
→ 取得經驗 → 選擇 Build → 擊敗 Boss → 解鎖下一區 → 持續逃亡
```

## 玩家如何移動

1. 點擊畫面並拉動方向。
2. 顯示直線彈射指引，只提示方向與拉力距離，不預告重力或潮流造成的偏移。
3. 放開後噴射；噴射方向與拉動方向一致。
4. 飛行結果再受到重力、水流、各水域規則與碰撞反彈影響。

因此玩家能規劃方向，但不能把每次落點當成完全精準的位移。

## 水域規則

水域以五級持續加速度改變玩家的垂直運動：

| 層級 | 水域 | 核心效果 |
| --- | --- | --- |
| `L3` | 深色 | `2.0G` 向下，快速下沉 |
| `L2` | 深藍過渡帶 | `1.5G` 向下，介於一般與高重力 |
| `L1` | 一般藍色 | `1.0G` 向下，基準重力 |
| `L0` | 中性色帶 | `0`，保留慣性，不自動停住 |
| `L-1` | 淺色 | `1.0G` 向上，持續上浮 |

## 核心取捨

- 用更多氧氣快速前進，或保守移動去找下一個氧氣點。
- 用體力頻繁瞄準與發射，或停下來等待恢復並降低風險。
- 擊敗敵人換取經驗與體力，或直接閃避以保留資源。
- 接受物理落點的不確定性，利用水域、潮流與反彈找出路。
- 把水域當成持續加速度，而不是直接改寫速度；彈射初速度、慣性與重力共同決定落點。

## 開發時不可偏離

- 氧氣必須同時牽動移動與生存，不能只是一條獨立的倒數條。
- 物理規則、水域規則與環境物件要共同形成路線決策。
- 直線指引只提供方向與距離，不承諾落點；重力與潮流偏移留給玩家透過經驗判斷。
- 實際運動與物理測試仍使用同一套固定步長運動學；顯示指引刻意不把這個結果提前揭露。
