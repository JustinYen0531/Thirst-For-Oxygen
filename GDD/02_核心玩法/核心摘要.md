# 02 核心玩法｜核心摘要

> 這一頁回答「玩家如何移動、如何做取捨，以及一輪遊戲如何前進」。

## 先記住

核心循環是：

```text
探索 → 彈射移動 → 消耗氧氣與體力 → 找到氧氣 → 擊敗或閃避敵人
→ 取得經驗 → 選擇 Build → 擊敗 Boss → 解鎖下一區 → 持續逃亡
```

## 玩家如何移動

1. 點擊畫面並拉動方向。
2. 顯示預測軌跡。
3. 放開後噴射；噴射方向與拉動方向一致。
4. 飛行結果再受到重力、水流、各水域規則與碰撞反彈影響。

因此玩家能規劃方向，但不能把每次落點當成完全精準的位移。

## 水域規則

| 水域 | 核心效果 |
| --- | --- |
| 深色 | 高重力，快速下沉 |
| 一般藍色 | 正常重力 |
| 中性色帶 | 零重力，可停留 |
| 淺色 | 持續上浮 |

## 核心取捨

- 用更多氧氣快速前進，或保守移動去找下一個氧氣點。
- 用體力頻繁瞄準與發射，或停下來等待恢復並降低風險。
- 擊敗敵人換取經驗與體力，或直接閃避以保留資源。
- 接受物理落點的不確定性，利用水域、潮流與反彈找出路。

## 開發時不可偏離

- 氧氣必須同時牽動移動與生存，不能只是一條獨立的倒數條。
- 物理規則、水域規則與環境物件要共同形成路線決策。
- 預測軌跡提供理解，不代表承諾精準落點。
