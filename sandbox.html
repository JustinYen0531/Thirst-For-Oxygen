開發者快捷鍵

快捷鍵不會改正式遊玩頁；只在這個沙盒套用測試覆寫。

開／關此視窗
Ctrl + Alt + D
武器槽拉滿
Alt + 1
被動槽拉滿
Alt + 2
Resonance 拉滿
Alt + 3
清除覆寫
Alt + 0

可用：weapon、passive、resonance、max weapons、max passives、max resonance、clear。

武器：knife、katana、trident、lightMachineGun
被動：oxygenCirculator、pressureStabilizer、ecologicalCarapace、abyssalAmplifier
Resonance：使用敵人 ID，例如 crabGuard、abyssalSpermWhale。

放置敵人

預設是潛水員操控模式：點擊潛水員周圍的高亮操控區，再拖曳方向與距離。要新增敵人時，先開啟放置敵人模式；放置模式也不會搶走操控區的判定。

玩家 Build

沙盒進入時 Build 全空；選擇武器或被動後立即生效，不必另外套用。武器可自由換位，已裝備武器會同時運作，槽位按鈕只改檢視焦點。
